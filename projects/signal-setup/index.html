Design notes

    On every screen
    • Every control is at least 48 px tall. WCAG 2.5.8 asks for 24 px; thumbs on a small, cheap screen need more.
    • “Listen” reads the screen aloud with the phone’s own voice, so nothing is downloaded. It is hidden if the phone cannot do it.
    • “Need help?” is in the same place on every screen (WCAG 3.2.6, Consistent Help).
    • The Android back button goes to the previous step, not out of the flow.
    • Progress is saved on the phone, so a power cut or the school bell does not mean starting again.
    • Focus moves to the new heading on each screen, and the page title names the step, so screen-reader users hear where they are.

    About this prototype

    A phone flow that lets school staff set up a speed-test box, so their school stops showing “No speed test” on the Classroom Signal dashboard.

    The school, the box code and every result are sample data. Waits that take minutes in real life take a few seconds here.
